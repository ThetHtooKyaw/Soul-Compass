# Souls Compass

A dynamic, interactive horoscope web application that lets users uncover their zodiac-related true self, strengths, weaknesses, and compatibility through an engaging date-driven experience.

---

## Features

* **Interactive Spinning Wheel:** Custom-built wheel that responds dynamically and smoothly to user interactions.
* **Custom Date Picker:** Scrollable date selection with smooth step-by-step transitions without relying on external UI libraries.
* **Fully Responsive:** Clean layout tailored for desktop, tablet, and mobile devices.

---

## Tech Stack

* **HTML5:** Semantic structure and content markup
* **CSS3:** Custom styles, media queries, and smooth animations
* **JavaScript (Vanilla JS):** Dynamic DOM manipulation, interaction logic, and date calculation routines
