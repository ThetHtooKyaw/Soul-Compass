# Souls Compass

A dynamic, interactive horoscope web application that lets users uncover their zodiac-related true self, strengths, weaknesses, and compatibility through an engaging date-driven experience.

---

## Features

- **Interactive Spinning Wheel:** Custom-built wheel that responds dynamically and smoothly to user interactions.
- **Custom Date Picker:** Scrollable date selection with smooth step-by-step transitions without relying on external UI libraries.
- **Fully Responsive:** Clean layout tailored for desktop, tablet, and mobile devices.

---

## Project Structure

```text
souls-compass/
├── index.html          # Main HTML document
├── css/
│   ├── main.css        # Primary stylesheet importing base styles
│   └── components/     # Modular CSS components (e.g., wheel, date picker)
├── js/
│   ├── main.js         # Entry point for JavaScript execution
│   └── components/     # Modular JS components and UI interactions
├── model/              
│   └── zodiac_model.js # Zodiac model
└── assets/             
    ├── icons/          # Images
    └── images/         # icons
```

---

## Tech Stack

- **Markup:** HTML5 for semantic structure and content markup
- **Styling:** CSS3 for custom styles, media queries, and smooth animations
- **Scripting:** Vanilla JavaScript (ES6+) for dynamic DOM manipulation, interaction logic, and date calculation routines
- **Deployment:** Vercel
